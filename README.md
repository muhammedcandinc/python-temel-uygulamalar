# Python Temel Algoritma Çalışmalarım

Bu depo, Yazılım Mühendisliği eğitimimin başında Python dilinin temel mantığını, döngüleri ve koşullu ifadeleri kavramak amacıyla geliştirdiğim ilk uygulamaları içermektedir.

## 🚀 Depo İçeriği
* **hesap_makinesi.py:** Kullanıcıdan alınan girdilerle temel matematiksel işlemleri gerçekleştiren ve döngü yapısını barındıran algoritma dosyası.
* **yas_hesaplama.py:** Doğum yılı bilgisini işleyerek dinamik yaş analizi yapan kod dosyası.

## 🛠️ Kullanılan Teknolojiler
